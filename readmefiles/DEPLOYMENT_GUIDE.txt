QUICK DEPLOYMENT GUIDE
======================

1. INSTALL CASPIANPETRO LIBRARY
   cd /path/to/project
   pip install -e .

2. BUILD DATA VAULT
   cd track_2_data_vault/scripts
   python3 build_data_vault.py

3. RUN DATA QUALITY TESTS
   cd track_2_data_vault/tests
   python3 data_quality_tests.py

4. BUILD DIMENSIONAL MODEL
   cd track_3_analytics/dimensional_model
   python3 run_etl.py

5. START DASHBOARD
   cd track_3_analytics/dashboard
   python3 app.py

6. DEPLOY AIRFLOW DAG
   cp data_pipeline/dags/socar_seismic_etl.py $AIRFLOW_HOME/dags/
   airflow dags trigger socar_seismic_etl

ACCESS POINTS
=============
- Dashboard: http://localhost:80
- Airflow: http://localhost:8080
- Data Vault: track_2_data_vault/vault_data/
- Dimensional DB: track_3_analytics/dimensional_model/dimensional_model.db
